# 한 번 더 — 아이폰 설치 가이드 (프로토타입 v0.2)

웹 프로토타입을 iOS 단축어 자동화에 연결하면, **증권앱을 여는 순간 '한 번 더'가 먼저 뜨는**
실제 인터셉트가 지금 폰에서 작동한다. 네이티브 앱·개발자 계정 없이.

## 1. 프로토타입 열어보기

호스팅 주소(GitHub Pages 활성화 후):
`https://dariajkim-star.github.io/decision-mirror/`

- Safari로 열고 공유 → **홈 화면에 추가** 하면 전체화면 앱처럼 동작
- v0.2부터 **오프라인 동작** (PWA) — 한 번 열어두면 지하철에서 네트워크 없이도 인터셉트가 뜬다
- 기록은 전부 이 폰의 localStorage에만 저장된다 (서버 전송 없음)

## 2. 단축어 자동화 연결 (핵심)

1. **단축어** 앱 → 하단 **자동화** 탭 → **+** → **개인용 자동화 생성**
2. **앱** 선택 → **선택** 에서 증권앱(키움·삼성증권·토스 등) 체크 → **열려 있음** → 다음
3. 동작 추가: **URL 열기** → 위 주소 입력
4. **"실행 전에 묻기" 끄기** ← 이걸 꺼야 자동으로 뜬다 (iOS 17+는 "즉시 실행" 선택)
5. 완료

이제 증권앱을 열면 → 증권앱이 뜨자마자 → Safari의 '한 번 더'가 위로 올라온다.
질문에 답하고 [계속하기]를 누르면 뒤에 이미 열려 있는 증권앱으로 돌아간다.

> 복귀가 매끄럽지 않으면: 프로토타입의 **데이터** 탭에서 증권앱 URL 스킴을 등록
> (예: 일부 앱은 `앱이름://` 스킴 지원). 비워두면 '뒤로가기'로 동작.

## 3. 알아둘 것

- **여러 증권앱**을 쓰면 2번에서 전부 체크하면 된다 (자동화 하나로 커버)
- 자동화를 끄면 인터셉트도 꺼진다 — 이 해제 가능성 자체가 기획의 알려진 한계(OI-1)
- 하루 쉬고 싶으면 **데이터 탭 → 스누즈** — 당일 질문 없이 통과되고 다음 날 자동 복귀 (FR-6)
- 시세만 보러 들어갈 땐 **[✕] 또는 "시세만 볼게요"** — 라벨 없이 통과되고 `browse_only`로 기록됨
