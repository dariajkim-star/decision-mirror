# Decision Mirror

**Formerly: No_FOMO**
**User-facing name: 한 번 더**

> 시장을 보기 전에, 내 상태를 한 번 더.

투자 추천기가 아니고, 심리 진단기도 아니다. **의사결정 과정을 비추는 시스템**이다.

---

## 무엇을 하는가

개인투자자는 시장 급등·커뮤니티 반응 같은 자극을 받았을 때 생리적 각성과 FOMO가 커져도, 그것이 자신의 투자 판단을 왜곡하고 있다는 사실을 실시간으로 알아차리기 어렵다. 기존 증권 서비스는 시장 상태만 보여줄 뿐 투자자 자신의 상태는 보여주지 않는다.

**투자자는 시장은 보지만, 흔들리고 있는 자기 자신은 보지 못한다.**

Decision Mirror는 **증권앱을 여는 순간** 사용자의 생체·행동 데이터가 먼저 나타나, 매매 직전 3초의 마찰과 이탈 경로를 만드는 **행동재무 실험 시스템**이다.

```
[증권앱 아이콘 터치]
      ↓ iOS 단축어 자동화
[한 번 더]가 먼저 열린다
      "지금 심박이 평소보다 높아요"        ← Polar H10 (BLE 실시간)
      "어젯밤 수면 5시간 10분"             ← HealthKit
      한 번 더?
      ↓
[계속하기] → 증권앱          [오늘은 그만] → 홈
```

이 경로는 one sec 연구(PNAS 2020, n=1,039)가 앱 열기 시도 36% 중단을 측정한 **바로 그 메커니즘**이다. 미검증 변형이 아니다.

## 무엇을 하지 않는가

- 종목 예측 / 적정 매수가 추천 / 투자자문
- 모든 고점 매수 방지
- 감정의 의학적 진단
- 수익률 보장
- **사용자의 숨은 심리("진짜 충동")를 판정하는 것**

모델이 예측하는 것은 마음이 아니라 **관측 가능한 행동**이다 — 위험 이벤트 이후 30분 내 체결 여부, 거래 반응시간, 평소 대비 주문 규모 변화.

## 무엇을 말할 수 있고, 무엇을 말하면 안 되는가

| 레벨 | 예시 | |
|---|---|---|
| **L1 사실** | "지금 심박이 평소보다 14 높아요" | ✅ |
| **L2 자기 이력 패턴** | "이런 상태에서 최근 5번 중 4번, 30분 안에 매수했어요" | ✅ **허용 상한** |
| **L3 판정** | "뇌동매매 위험이 높습니다" | ❌ **금지** |

L3를 금지하는 이유는 셋이다.

- **법** — "지금 위험하다"는 뒤집으면 "지금은 사지 마라", 곧 **시기에 대한 판단**이다. 자본시장법상 투자자문 해석 여지가 열리고, 심리 상태 판정은 의료기기 리스크까지 건드린다
- **과학** — 충동인지 확신인지는 **관측 불가능한 내적 상태**다. 정답지가 없는 것을 판정하면 검증도 반증도 되지 않는다
- **행동과학** — 숙고·경고 메시지는 효과 크기가 **0**이다(one sec). 판정은 방어를 유발하고, 우리 데이터의 1위 감정인 분노·외부귀인(246건)이 앱으로 향한다

정확히 말하면 이 제품은 "판정하지 않는" 것이 아니라 **"판정을 통보하지 않는"** 것이다. 내부적으로는 위험 이벤트를 판정해 트리거로 쓰되, 사용자에게는 판정 결과가 아니라 그 **근거 관측치**만 보여준다.

## 단계

```
Decision Mirror (한 번 더)
├─ Silent Calibration   수집만. 행동 피드백 없음. 개인 기준선 확보
├─ Mirror Mode          관측 사실 + 중립적 의도 확인. 판정하지 않음
└─ Guard Mode           설명 가능한 위험 신호. 근거 공개형 개입
```

Silent Calibration에서는 인터셉트가 **화면 없이 통과**하며 발화 기록만 남긴다. `오늘 금융앱 14회 확인` 같은 행동 수치를 보여주는 순간 행동이 달라지기 때문이다(관측자 효과). 시스템 상태(`기준선 계산용 데이터 8일 수집`)만 노출한다.

## 구성

| 소스 | 데이터 | 등급 |
|---|---|---|
| **Polar H10** (가슴 스트랩, BLE) | RR 간격 실시간 스트림 | 연구급 — HRV 연구에서 ECG 대비 검증된 준거 기기 |
| **HealthKit** (폴백) | 수면, 안정시 심박 | 소비자급. H10 미착용 시에도 L1 한 줄은 항상 표시 |
| **인터셉트 실행 기록** | 증권앱 열람 로그 | 별도 감지 API 불필요 — 부산물로 확보 |

배포는 개인 개발자 계정 사이드로드(n=1). **스토어 심사·정책 리스크 없음.**

## 검증 가설

| # | 가설 | 위상 | 기각 조건 |
|---|---|---|---|
| **H4** | 사용 후 자기평가와 실제 행동의 일치도가 개선된다 | **주가설** | Brier score 미개선 |
| H1 | 생체·행동을 더한 모델이 시장 데이터만 쓴 모델보다 30분 내 체결을 더 잘 예측한다 | 주가설 | 예측력 차이 없음 |
| H3 | H10 착용 세션이 미착용(HealthKit만) 세션보다 성과가 좋다 | 주가설 | 차이 없음 → **웨어러블 제거, 행동-only 재편** |
| H2 | 인터셉트 화면 활성 세션이 통과 세션보다 체결까지 시간을 늘린다 | 보조 | 차이 없음 |

H4가 주가설인 이유: 이 제품의 효용은 위험한 그 순간에 개입하는 것이 아니라, **반복 노출로 자기 신체 상태를 읽는 능력을 기르는 것**에 있다. 거울의 효용은 거울 앞에 선 그 순간이 아니라 매일 봐서 자기 얼굴을 알게 되는 데 있다.

'상태 맹시(state blindness)'는 전제가 아니라 **반증 가능한 가설**이다. 위 가설들이 죽으면 프로젝트 전제도 죽는다.

## 설계 금지 사항

행동·생체 지표 화면에서 금지: 스트릭, 배지, 랭킹, 타 사용자 비교, 총점·등급, 목표 달성률, 연속 성공일, 빨강/초록 합격·실패 표시, "좋아졌습니다/나빠졌습니다", "오늘은 잘 참았습니다", 숫자를 보러 재진입시키는 푸시, 실시간 행동 카운터의 홈 화면 상시 노출.

금융앱 확인 강박을 Decision Mirror 확인 강박으로 바꾸면 자책골이다.

허용: 데이터 연결 여부, 수집 누락, 기준선 계산 진행 상태, 센서 배터리·동기화 등 **운영 정보만**.
