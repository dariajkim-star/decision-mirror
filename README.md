# Decision Mirror

**Formerly: No_FOMO** · **User-facing name: 한 번 더**

> 사기 전에, 근거 한 번 더.

투자 추천기가 아니고, 심리 진단기도 아니다. **매수 직전에 "왜 사는가"를 묻고 기록하는 거울**이다.

---

## 문제

> 데이터가 아니라 심리 — 공포, 탐욕, 분위기 — 에 의해 매매를 하고, 물린다.

이 pain point가 실제 시장에 있는지 확인하는 것에서 프로젝트가 시작됐다.

## 시장 검증 (P0)

4개 채널 5,022건 크롤링 → 매매 언급 글 **268건 전수**를 **독립 판정자 2명**이 분류 (일치율 89.6%, kappa 0.73):

- 매매 근거를 밝힌 글 **26건 중 24건(92%, 95% CI [76–98%])이 심리 주도** — 데이터 주도는 1건
- 심리 주도 매매의 **46%(CI [28–65%])가 손실·물림·후회**를 함께 보고
- **복수매매(물타기·복구)는 4건 전원 손실** — 두 판정자가 독립적으로 동일 결론

> *"이재명 최태원 말듣고 샀다가 인버스로 80% 복구중"*
> *"고점에 물려 2달동안 고문받고있다..물타고 물타도 손실만 더 키웠는데"*

보조 발견: 감정 분석(층화 추정) 결과 지배 감정은 분노·외부귀인(85.7%), FOMO 언어화는 0.8%. 상위 키워드는 '실적·투자·반도체'. **심리는 분노와 합리화의 언어 뒤에 숨는다 — 텍스트만으로는 실시간 포착이 불가능하다.**

## 제품

```
[증권앱 아이콘 터치]
      ↓ iOS 단축어 자동화 (one sec과 동일한 실증 경로 — PNAS 2020, 앱 열기 36% 중단)
[한 번 더]가 먼저 열린다

      이 매수의 근거는?
      [ 실적·분석이 있다 ]  [ 분위기·감이다 ]  [ 모르겠다 ]
      (보조: 지금 심박 평소+14 · 어젯밤 수면 5h 10m)

[계속하기] → 증권앱        [오늘은 그만] → 홈
```

**탭 하나가 세 가지 일을 한다:**

1. **마찰** — 답을 고르는 3초가 자동반응을 의식적 결정으로 바꾼다
2. **라벨** — 합리화가 완성되기 전, 매수 직전의 자기 판단이 기록된다
3. **거울** — 체결 데이터와 만나 반박 불가능한 문장이 된다:

> **"'분위기·감'으로 산 최근 5건: 평균 −12%. '실적·분석'으로 산 3건: +2%."**

장기적으로는 **심리매매 지수** — VIX가 시장의 공포를 재듯, 내 매매에서 심리가 차지하는 비율을 잰다.

## 말할 수 있는 것과 없는 것

| 레벨 | 예시 | |
|---|---|---|
| L1 사실 | "지금 심박이 평소보다 14 높아요" | ✅ 보조 |
| **L2 자기 이력** | "'분위기·감'으로 산 최근 5건 평균 −12%" | ✅ **핵심** |
| L3 판정 | "심리 매매입니다" / "사지 마세요" | ❌ 금지 |

L3 금지의 3중 근거 — **법**(시기 판단=투자자문 리스크), **과학**(내적 상태는 관측 불가·반증 불가), **행동과학**(설교는 효과 0, 판정은 방어 유발 — 커뮤니티 지배 감정인 분노·외부귀인이 앱으로 향한다). **질문은 판정이 아니다.**

## 검증 가설 (n=1, owner 계좌·신체로 먼저)

| # | 가설 | 위상 |
|---|---|---|
| **H4** | 사용에 따라 심리매매 지수가 감소하고 자가예측 정확도가 개선된다 | **주가설** |
| H1 | "분위기·감" 매수는 "실적·분석" 매수보다 성과가 나쁘다 (시장 검증의 본인 계좌 재현) | 주가설 |
| H3 | "감" 매수 시 생체 각성이 동반되며 예측에 추가 가치를 준다 — 없으면 웨어러블 제거 | 주가설 |
| H2 | 질문 표시 세션이 통과 세션보다 매수 전환율·규모를 낮춘다 (무작위 배정) | 보조 |

생체 신호(Polar H10 + HealthKit)는 문제의 전부가 아니라 **조기 신호 후보**다. owner 1년 베이스라인 확보됨: 안정시 심박 46.8bpm, 수면 6.8h(변동 4.0~10.7h), HRV 54ms.

## 설계 금지

게이미피케이션 전면 금지(스트릭·배지·랭킹·달성률·평가어·재진입 푸시). 심리매매 지수는 월 단위·평가어 없이만. *금융앱 확인 강박을 '한 번 더' 확인 강박으로 바꾸면 자책골이다.*
