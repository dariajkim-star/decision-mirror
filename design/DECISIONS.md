# 디자인 결정 기록

## 2026-08-05 — daria 디자인 v2 채택 (4화면)

daria가 제작한 디자인 시안이 목업 v1(mockup_v1.html)을 대체한다. 확정 사항:

### 질문 문구
> **"지금 이 매매의 이유는 무엇인가요?"** (부제: 하나를 선택해 주세요)

- "매수" → **"매매"**: 인터셉트는 증권앱 실행 시점에 발화하므로 매수/매도를 구분할 수 없다.
  "매매"가 정확하며, **매도(패닉셀·투매) 결정도 라벨링 대상**이 된다 — 범위 확장.
- "근거" → "이유": 더 자연스러운 입말.

### 3버튼 분류 체계 (라벨 스키마 v2)

| 버튼 | 아이콘 | 포착하는 것 | 구 스키마 대응 |
|---|---|---|---|
| **분석/전략** | 📊 | 실적·밸류·기술적 분석, 사전 계획의 실행 | 실적·분석이 있다 |
| **감정/기분** | ❤️ | 분위기 편승, 군집, 조바심, 공포 | 분위기·감이다 |
| **습관/반복** | 🌱 | 루틴 매매, 물타기 반복, 자동반응 | (신설 — '모르겠다'의 정직한 버전) |

- "모르겠다" 제거: 저항 없는 탈출구가 사라져 응답 피로(OI-2) 위험이 소폭 상승하나,
  "습관/반복"이 사실상 그 역할을 하며 **복수매매 패턴을 자기 라벨로 직접 포착**하는 이득이 더 큼.
- 시장 검증 매핑: 심리매매 지수 = **감정/기분 + 습관/반복** 라벨 비율.
- 무응답([X]로 닫기/[계속하기] 직행)은 여전히 허용되며 기록된다(FR-5).

### 화면별 확정 요소

1. **① 인터셉트**: 질문 + 3버튼 + [계속하기] + 우상단 [X]. 하단 카드에 L1(심박·수면)
2. **①b 복수매매 변형**: 상단 맥락 2줄("이 종목은 현재 −18% 보유 중이에요. 직전 매수는 7월 22일이었어요") — 사실만, 명명·판정 없음
3. **② 거울(L2)**: "최근 30일 근거별 매매 성과" + 디스클레이머("평가는 하지 않아요. 숫자는 당신의 기록이에요") + 0 기준 양방향 가로막대 + 하단 데이터 범위 카드
4. **③ 심리매매 지수**: 월 단위 막대(직접 라벨), **"산식 및 기준: 고정 · 업데이트: 매월 1일"** 명시 — 산식 고정 선언은 신뢰 장치

### 수정 필요 (차기 시안 반영)

- ⚠️ **"기록은 익명으로 저장돼요" → "기록은 이 기기에만 저장돼요"**
  아키텍처는 익명화가 아니라 온디바이스(NFR-6, 원시 데이터 서버 미전송).
  '익명'은 서버 저장을 암시해 부정확하며, '기기에만'이 사실이자 더 강한 프라이버시 주장.
