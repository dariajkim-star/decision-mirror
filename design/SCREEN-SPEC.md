# 한 번 더 — 화면 스펙 v2.1

> daria 디자인 v2를 기준으로, 기획(PRD v3)과 어긋난 3곳을 수정한 확정 스펙.
> 변경점: ① [오늘은 그만] 복원 ② L1을 기준선 대비 편차로 ③ 무라벨 통과 경로 신설 ④ 저장 문구 정정.
> 디자인 토큰·비주얼은 daria 시안을 따른다. 이 문서는 **내용·동작·기록**을 정의한다.

---

## 화면 ① 인터셉트 (기본)

**발화 조건**: 지정 증권앱 실행 → iOS 단축어 자동화로 '한 번 더'가 먼저 열림 (FR-1)
**성능**: 콜드 스타트 포함 1초 내 표시. 3초 안에 읽히는 분량 (NFR-1)

```
┌─────────────────────────────┐
│                        [X]  │  ← X = "시세만 볼게요"와 동일 동작 (아래 참조)
│                             │
│   지금 이 매매의             │
│   이유는 무엇인가요?          │
│   하나를 선택해 주세요         │
│                             │
│   ┌───────────────────┐     │
│   │ 📊 분석/전략        │     │
│   ├───────────────────┤     │
│   │ ❤️ 감정/기분        │     │
│   ├───────────────────┤     │
│   │ 🌱 습관/반복        │     │
│   └───────────────────┘     │
│                             │
│   시세만 볼게요 ›            │  ← 텍스트 링크 (무라벨 통과)
│                             │
│  ┌───────────┬───────────┐  │
│  │ 오늘은 그만 │  계속하기   │  │  ← 2버튼. '오늘은 그만'은 항상 표시 (FR-4)
│  └───────────┴───────────┘  │
│                             │
│  ┌─────────────────────┐    │
│  │ 🔒 기록은 이 기기에만    │    │
│  │    저장돼요            │    │
│  │ 심박 평소보다 +14        │    │
│  │ · 어젯밤 수면 6h 20m    │    │
│  └─────────────────────┘    │
└─────────────────────────────┘
```

### 요소 정의

| 요소 | 사양 | 근거 |
|---|---|---|
| 질문 | "지금 이 매매의 이유는 무엇인가요?" + 부제 "하나를 선택해 주세요" | daria v2 확정 |
| 3버튼 | 분석/전략 · 감정/기분 · 습관/반복. **선택은 토글**(재탭 시 해제), 단일 선택 | FR-2 |
| **시세만 볼게요** | 텍스트 링크. 탭 → 라벨 없이 증권앱 진입. `browse_only`로 기록 | **신설** — 매매 의도 없는 진입의 라벨 오염 방지 (판정표 오탐 케이스, FR-5) |
| **오늘은 그만** | 좌측 버튼(보조 스타일). 탭 → 홈으로. 당일 재발화 시에도 동일 화면(차단 아님) | **복원** — one sec 효과 1위 프리미티브 = 명시적 이탈 경로 (§2.3, FR-4) |
| 계속하기 | 우측 버튼(주 스타일). 라벨 선택 여부와 무관하게 활성 — **무응답 통과 허용** | FR-5 (무응답도 데이터) |
| [X] | "시세만 볼게요"와 동일 동작·동일 기록. (닫기처럼 보이지만 의미를 부여) | 플로우 모호성 제거 |
| L1 보조 카드 | **"심박 평소보다 +14 · 어젯밤 수면 6h 20m"** — 절대값 금지, 동일 시간대 개인 기준선 대비 편차만. H10 미착용 시 심박 항목 생략하고 수면만 | NFR(기준선 대비), FR-3, 우아한 강등 |
| 저장 문구 | **"기록은 이 기기에만 저장돼요"** ('익명' 금지 — 온디바이스가 사실) | NFR-6, DECISIONS.md |

### 기록 (모든 경로가 데이터)

| 사용자 행동 | 기록 |
|---|---|
| 라벨 선택 + 계속하기 | `label={분석전략|감정기분|습관반복}, action=continue, t_dwell` |
| 라벨 없이 계속하기 | `label=none, action=continue, t_dwell` |
| 시세만 볼게요 / [X] | `label=null, action=browse_only, t_dwell` |
| 오늘은 그만 | `label=(선택돼 있었다면 그 값), action=stop_today, t_dwell` |
| 스누즈(설정에서) | `action=snooze` (FR-6) |

`t_dwell` = 화면 표시 → 이탈까지 ms. H2 통과(pass-through) 배정 세션은 화면 없이 발화 기록만 남긴다(FR-9).

### 금지

- 판정·권고 문구 일절 (FR-8): "감정적이시네요", "신중하세요" 등
- 라벨 선택 강제 (계속하기 비활성화 금지)
- "오늘은 그만" 숨김·축소·회색 처리로 진행 유도하는 다크패턴

## 화면 ①b 인터셉트 — 복수매매 변형

**발화 조건**: 기본 인터셉트 조건 + **현재 손실 보유 중인 종목의 재진입 감지** (체결 이력 기반, FR-15)

기본 화면과 동일하되, 질문 위에 맥락 카드 추가:

```
│  ┌─────────────────────┐    │
│  │ 이 종목은 현재 −18%     │    │
│  │ 보유 중이에요.          │    │
│  │ 직전 매수는 7월 22일    │    │
│  │ 이었어요.              │    │
│  └─────────────────────┘    │
```

- **사실 2줄만**: 보유 손익률, 직전 매수일. 체결 이력에서 자동 산출
- 금지: "물타기네요", "복수매매" 등 명명·판정 (L3). 색상 강조도 중립 유지 (경고색 금지)
- 나머지 요소·기록은 ①과 동일. 기록에 `context=reentry` 플래그 추가

## 화면 ② 거울 (L2) — 근거별 매매 기록 (v1 = 행동 사실만)

> **v2.2 개정 (README §4 '거울은 두 층이다' 반영)**: 거울 v1은 **1층 행동 사실**만 —
> 라벨 비율·응답 시간·반복 발화. **수익률(2층)은 유예된 별도 결정**이며, 이 화면은
> 수익률을 약속하지 않는다 ("집계 대기" 등 대기실 문구 금지). 정체성: 성찰 도구,
> 손실 교정 도구 아님. 수익률 층이 훗날 승인되면 그때 별도 스펙으로 추가한다.

**진입**: 앱 내 탭 (푸시로 유도하지 않음 — 재진입 유도 푸시 금지)

```
│  ‹ 최근 30일 근거별 매매 기록  │
│                             │
│  평가는 하지 않아요.          │
│  숫자는 당신의 기록이에요.     │
│                             │
│  라벨 12건 중                │
│  분석/전략 3건 ██▌      25%  │
│  감정/기분 5건 ████▏    42%  │
│  습관/반복 4건 ███▎     33%  │
│                             │
│  '감정/기분'을 고르기까지      │
│  평균 1.8초,                │
│  '분석/전략'은 4.6초 걸렸어요. │
│  같은 날 두 번 이상 연 날이    │
│  4일 있었어요.               │
│                             │
│  ┌─────────────────────┐    │
│  │ 🛡 데이터 범위: 최근 30일 │    │
│  │ 인터셉트 19회 · 오늘은   │    │
│  │ 그만 2회 · 시세만 4회    │    │
│  │ 라벨 응답률 83%         │    │
│  └─────────────────────┘    │
└─────────────────────────────┘
```

- 내용은 전부 **라벨 기록만으로 산출**: 라벨 비율, 라벨별 평균 응답 시간(t_dwell), 같은 날 복수 발화 일수, 이탈 경로 횟수
- 막대: 좌기점 비율 막대, 값 직접 라벨, 중립 네이비 단색 (수익=초록/손실=빨강 금지)
- **건수 표기 필수** ("3건") — 소표본 과신 방지
- 라벨군 3건 미만이면 해당 응답 시간 등 파생 수치 비표시 — "기록이 더 쌓이면 보여드릴게요" (통계적 과장 방지)
- 문장은 사실 서술만. "좋아요/아쉬워요" 금지. **수익률 예고·대기 문구 금지**

## 화면 ③ 심리매매 지수

**진입**: 앱 내 탭. 갱신: 매월 1일 (실시간 금지)

```
│  ‹ 심리매매 지수              │
│    월 단위                   │
│                             │
│    52   45   40   33        │
│    ██   ██   █▊   █▌        │
│    5월  6월  7월  8월         │
│                             │
│  8월 매매 9건 중              │
│  감정/기분·습관/반복 3건.      │
│                             │
│  ┌─────────────────────┐    │
│  │ 🛡 산식 및 기준: 고정    │    │
│  │ = (감정/기분+습관/반복)  │    │
│  │   ÷ 전체 라벨 매매      │    │
│  │ 업데이트: 매월 1일       │    │
│  └─────────────────────┘    │
```

- 산식을 **화면에 노출** (daria v2의 "산식 고정" 카드 유지 + 산식 자체 병기)
- 현재 월만 강조색, 나머지 중립 (색 하나 = 의미 하나)
- 추세 코멘트 금지 ("절반으로 줄었어요" ❌) — 추이는 막대가 말한다
- 목표선·달성률·연속기록 없음

## 상태 매트릭스 (공통)

| 상태 | 인터셉트 동작 |
|---|---|
| Phase A (Silent) | 화면 없이 통과, 발화만 기록 |
| Phase B, 표시 배정 | 화면 ① 또는 ①b |
| Phase B, 통과 배정 | 화면 없이 통과, 발화 기록 (H2 통제군) |
| H10 연결됨 | L1에 심박 편차 + 수면 |
| H10 미연결 | L1에 수면만 (심박 항목 생략, 오류 표시 없음) |
| 자동화 해제 감지 | 앱 대시보드에만 표시 — 복구 유도 푸시 금지 |
| 스누즈 중 | 당일 발화 없음, 다음 거래일 자동 복귀 |
