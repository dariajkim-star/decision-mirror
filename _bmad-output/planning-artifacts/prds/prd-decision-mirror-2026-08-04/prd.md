# Decision Mirror — Product Requirements Document

> **한 줄 정의**: 증권앱을 여는 순간 **"이 매수의 근거는?"** 한 번을 묻는다. 그 탭 하나가 마찰이자, 기록이자, 나중의 거울이 된다. 심리(공포·탐욕·분위기)에 의한 매매가 데이터에 의한 매매를 밀어내는 것 — 그것이 이 제품이 없애려는 것이다.
>
> **사용자 대면명**: 한 번 더 — *사기 전에, 근거 한 번 더.*
> **프로젝트명**: Decision Mirror (구 No_FOMO)

---

## 1. 문제

### 1.1 문제의식 (owner 1인칭)

> 데이터가 아니라 VIX지수 같은 심리 — 공포, 탐욕, 분위기 — 에 의해 매매를 하고 물리는 상황을 없애고 싶다.

개인투자자의 매수·매도는 실적·밸류에이션 같은 데이터가 아니라 급등하는 분위기, 남들이 번다는 소식, 복구하고 싶은 조바심에 의해 결정되는 경우가 많다. 그리고 그 매매는 물림으로 끝난다. 이것이 실제 시장에 존재하는 pain point인지 확인하는 것에서 이 프로젝트가 시작됐다.

### 1.2 시장 검증 — 크롤링은 이 질문에 답하기 위해 수행됐다

4개 채널(네이버 종목토론방·디시 주식갤·유튜브 삼프로TV/슈카월드) **5,022건**을 수집하고, 매매를 언급한 글 268건 중 표본 220건을 **독립 판정자 2명**이 분류했다(일치율 92.3%, Cohen's kappa 0.79). 판정자는 서로의 라벨과 기계 태그를 보지 않고 원문만 읽었다.

**합의 기준 결과:**

| # | 발견 | 수치 |
|---|---|---|
| 1 | 매매 근거를 밝힌 글 중 **심리 주도** | **21/23건 (91%)** — 데이터 주도는 1건 |
| 2 | 심리 주도 매매 중 **손실·물림·후회 동반** | **11/21건 (52%)** — 수익 언급 3건 |
| 3 | **복수매매(물타기·복구 목적) 손실률** | **4/4건 (100%)** — 두 판정자가 독립적으로 동일 결론 |

실제 목소리: *"이재명 최태원 말듣고 샀다가 인버스로 80% 복구중"*(군집), *"고점에 물려 2달동안 고문받고있다..물타고 물타도 손실만 더 키웠는데"*(복수매매), *"본전만 올라오면 국장 정리하고 미장으로 몰빵간다"*(다음 심리 매매의 예약).

**보조 발견** — 감정 분석(판정자 채점, 층화 추정)에서 커뮤니티 지배 감정은 분노·외부귀인(85.7%)이었고 FOMO 언어화는 0.8%에 불과했다. 심리는 **분노와 합리화의 언어 뒤에 숨는다.** 빈도 상위 키워드가 '실적·투자·반도체'라는 사실과 합치면: **텍스트만으로는 심리 주도 매매를 실시간 포착할 수 없다.**

**한계 (명시)**: 근거가 드러난 매매는 23건으로 신뢰구간이 넓다. outcome은 자기보고라 물린 사람이 더 쓰는 생존 편향이 가능하다. "데이터 주도 1건"은 커뮤니티 글쓰기 관행의 반영일 수 있다. 데이터 무결성: 전 행 고유 ID·해시(`master_dataset.csv`), 인용문 claim 병기 검증(`verify_quotes.py`), 채점표(`trade_basis_report.md`, `lexicon_scorecard.md`).

### 1.3 Pain Point

| # | Pain Point | 근거 |
|---|---|---|
| PP1 | **매매의 근거가 심리다** — 분위기·군집·조바심·복구 욕구가 결정을 만든다 | §1.2 발견 1 (91%) |
| PP2 | **심리 매매는 물림과 짝지어 나타난다** — 특히 복수매매가 가장 파괴적 | §1.2 발견 2·3 |
| PP3 | **기존 도구는 전부 사후거나 가속이다** — 저널은 거래 후 회고, 증권앱·커뮤니티는 급등 알림·수익 인증으로 가속만. **매수 직전에 근거를 묻는 것은 없다** | 경쟁 분석 (research-landscape.md) |
| PP4 | **반복해도 학습이 없다** — 결과(수익률)는 기록되지만 **그때 근거가 뭐였는지**는 기록되지 않는다 | *"내일 항상 이런 마음을 가진다 아..어제 손절 칠걸"* (DM-001105) |
| PP5 | **텍스트·자가 회고로는 못 잡는다** — 심리는 실적의 언어로 합리화된다 | §1.2 보조 발견 |

### 1.4 포지셔닝

```
                 사후 회고               매수 직전
결과 기록        트레이딩 저널 전부         —
근거 기록        Edgewonk Tiltmeter        ★ Decision Mirror
                 (감정 태그, 수기·사후)      ("근거는?" — 그 순간, 탭 하나)
```

> 기존 저널은 **무엇을 샀는지** 기록하고, Decision Mirror는 **왜 샀는지**를 — 사기 전에 — 기록한다.

## 2. 솔루션

### 2.1 스파인

```
① 문제       사람들은 데이터가 아니라 심리로 매매하고, 물린다
② 시장 검증   매매 글 분류: 심리 주도 91%, 그중 절반 물림, 복수매매 전원 손실
③ 공백       매수 직전에 "근거"를 묻는 도구는 없다
④ 제품       증권앱을 여는 순간 묻는다: "이 매수의 근거는?"
             — 탭 하나 = 마찰 + 라벨 + 나중의 거울
⑤ 확장       근거 기록에 몸 상태(심박·수면)를 붙여 조기 신호를 학습
⑥ n=1        전부 내 계좌·내 몸으로 먼저 검증
```

### 2.2 핵심 인터랙션 — 근거 질문 인터셉트

```
[증권앱 아이콘 터치]
        ↓ iOS 단축어 자동화 (순정 기능, 심사 무관 — one sec과 동일한 실증 경로)
[한 번 더]가 먼저 열린다

        이 매수의 근거는?
        ┌──────────────────┐
        │  실적·분석이 있다      │
        │  분위기·감이다        │
        │  모르겠다            │
        └──────────────────┘
        (보조 표시: 지금 심박 평소+14 · 어젯밤 수면 5h 10m)

        ↓ 어느 버튼이든
[계속하기] → 증권앱          [오늘은 그만] → 홈
```

**탭 하나가 세 가지 일을 한다:**

1. **마찰** — 답을 고르는 3초가 자동반응을 의식적 결정으로 바꾼다 (one sec: 유효한 개입은 마찰과 이탈 경로뿐, 설교는 효과 0)
2. **라벨** — 매수 **직전**, 합리화가 완성되기 전의 자기 판단이 기록된다. 사전 등록(채택률 낮음)도 사후 회고(오염됨)도 아닌 제3의 라벨 수집 경로. 체결 데이터와 붙으면 근거별 성과가 자동 산출된다
3. **거울** — 축적된 기록이 L2가 된다:

> **"'분위기·감'으로 산 최근 5건: 평균 −12%. '실적·분석'으로 산 3건: +2%."**

반박이 불가능하다 — 자기가 누른 버튼이므로.

**자기기만 대응**: "실적·분석 있다"를 습관적으로 눌러도 30일 성과가 결국 산출된다. 그 불일치 역시 판정 없이 기록·표시한다(문구는 L2 원칙 내에서 별도 설계).

**복수매매 쐐기**: 가장 파괴적인 패턴(4/4 손실)이 가장 감지하기 쉽다 — 손실 중 종목 재진입은 체결 이력만으로 식별된다. 이 경우 질문에 맥락 한 줄이 붙는다 (문구는 판정 금지 원칙 내에서 설계).

### 2.3 문구 스펙트럼 (유지)

| 레벨 | 예시 | 허용 |
|---|---|---|
| L1 사실 | "지금 심박이 평소보다 14 높아요" | ✅ 보조 표시 |
| **L2 자기 이력** | "'분위기·감'으로 산 최근 5건 평균 −12%" | ✅ **핵심** |
| L3 판정 | "심리 매매입니다 / 사지 마세요" | ❌ 금지 |

L3 금지의 3중 근거(법: 시기 판단=자문업 / 과학: 내적 상태 관측 불가 / 행동과학: 판정은 방어 유발, 지배 감정인 분노·외부귀인이 앱으로 향함)는 v2와 동일. **질문은 판정이 아니다** — 규제 안전지대가 유지된다.

### 2.4 심리매매 지수 (장기)

VIX가 시장의 공포를 재듯, 축적된 근거 라벨로 **내 매매에서 심리가 차지하는 비율**을 잰다: "이번 달 심리 매매 40% → 25%". 게이미피케이션 금지 원칙(스트릭·배지·달성률 없음) 안에서 표시 가능한 유일한 종합 지표. 월 단위, 평가어 없이.

### 2.5 생체 신호의 위치 (강등이자 정위치)

심박·수면·HRV는 문제의 전부가 아니라 **심리 주도 매매의 조기 신호 후보**다. 근거 라벨이 생겼으므로 검증이 명확해졌다: "분위기·감" 라벨 매수 때 실제로 각성이 동반되는가(H3). 동반된다면 라벨이 쌓인 뒤 **질문이 뜨기 전에** 위험 구간을 예측할 수 있다(⑤).

- 센서: Polar H10(BLE 실시간 RR, 연구급) + HealthKit 폴백(수면·안정시 심박 — H10 미착용 시에도 보조 표시 유지)
- owner 베이스라인 확보됨(`ingest/`): 안정시 심박 46.8bpm, 수면 주평균 6.8h(변동 4.0~10.7h), 야간 HRV 54ms. 수면 변동성이 큰 프로파일이라 보조 표시의 정보 가치가 높다

## 3. 검증 (n=1)

### 3.1 가설

| # | 가설 | 위상 | 기각 조건 |
|---|---|---|---|
| **H4** | 사용 기간에 따라 **심리매매 지수가 감소**하고, 아침 자가예측("오늘 심리 매매 위험")의 정확도(Brier)가 개선된다 | **주가설** | 지수·정확도 모두 미개선 |
| **H1** | "분위기·감" 라벨 매수는 "실적·분석" 라벨 매수보다 성과가 나쁘거나 반응 시간이 짧다 (크롤링 발견 2의 본인 계좌 재현) | 주가설 | 근거별 차이 없음 → **제품 전제 약화** |
| **H3** | "분위기·감" 라벨 매수 시 생체 각성(심박·HRV 이탈)이 동반되며, 생체 신호가 행동 신호 대비 추가 예측력을 준다 | 주가설 | 추가 가치 없음 → 웨어러블 제거, 근거 질문만으로 재편(제품은 생존) |
| **H2** | 질문 표시 세션은 통과 세션보다 매수 전환율·주문 규모를 낮추거나 "오늘은 그만" 선택을 만든다 | 보조 | 차이 없음 |

**H2 설계**: 인터셉트 발화 시 질문 표시/조용한 통과를 무작위 배정. 통과 건도 발화·라벨 외 데이터는 기록. 인터셉트는 진입 경로 위에 있어 처치 전달이 보장된다(ITT≒처치). 사용자는 실험 설계에 사전 동의.

**독립 ground truth**: 증권사 거래내역 CSV(체결시각·가격·수량). 근거 라벨(자가)과 성과(실측)의 결합이 이 검증의 축 — 자가보고는 정답지가 아니라 **예측 대상이자 분석 축**이다.

**실패 조건**: 근거별 성과 차이 없음 / 질문이 매매 행동을 전혀 바꾸지 않음 / 라벨 응답률이 낮아 데이터가 안 쌓임 / 개입이 오히려 앱 확인·불안 증가 / 생체 추가 가치 없음(→H3 축소로 흡수).

### 3.2 판정표 (사건 단위)

| 상황 | 판정 |
|---|---|
| 질문에 답하고 [계속하기] → 매수 | **성공** — 안 사게 하는 게 아니라 **알고 사게** 한다 |
| [오늘은 그만] / 보류 | **성공** |
| 자동화 해제 후 매수 | 개입 실패 (해제는 감지·기록됨) |
| 매수 의도 없는 시세 확인에 과도한 마찰 | 마찰 비용 — 스누즈로 완화, 빈도 기록 |
| 매수 후 손실 | **판정 근거 아님** |

### 3.3 KPI

**① 심리매매 지수(주지표)** — 월별 "분위기·감"+"모르겠다" 라벨 비율. H4의 조작적 정의
**② 근거별 성과 분리** — 라벨별 30일 수익률·보유기간·회전율 (H1)
**③ 개입** — 질문 응답률, "오늘은 그만" 선택률, 표시/통과 세션의 매수 전환율·규모 차이 (H2)
**④ 신호** — "감" 라벨 시 생체 각성 동반률, 예측 모델의 추가 설명력 (H3)
**⑤ 운영** — 인터셉트 발화율(자동화 해제 감지), H10 착용률, 라벨 무응답률

## 4. 기능 요구사항 (v3)

### FG-1. 근거 질문 인터셉트

- **FR-1** iOS 단축어 자동화로 지정 증권앱 실행 시 '한 번 더'가 먼저 열린다 (설정 가이드 내장)
- **FR-2** 화면은 질문 "이 매수의 근거는?"과 3버튼을 표시한다: **[실적·분석이 있다] [분위기·감이다] [모르겠다]**
- **FR-3** 보조 영역에 L1 사실(심박 편차, 어젯밤 수면)을 표시한다. H10 미착용 시 HealthKit 데이터로 대체
- **FR-4** 모든 화면에 [계속하기]와 [오늘은 그만]을 제시하고 두 선택 모두 기록한다
- **FR-5** 응답·무응답·소요 시간·시각을 기록한다 (무응답도 데이터)
- **FR-6** 스누즈(당일 비활성) 가능, 스누즈도 기록
- **FR-7** 자동화 미설정·해제 상태를 감지해 표시한다
- **FR-8** L3 판정 문구는 코드 수준에서 존재하지 않는다
- **FR-9** H2: 발화 시 질문 표시/통과를 무작위 배정하고 배정 결과를 기록한다

### FG-2. 근거 장부(basis ledger)와 거울

- **FR-10** 사용자는 증권사 거래내역 CSV(체결시각·가격·수량)를 업로드할 수 있다
- **FR-11** 시스템은 근거 라벨과 체결을 시각 기준으로 매칭한다 (라벨 후 N시간 내 체결 = 해당 라벨의 매매)
- **FR-12** 근거별 성과(30일 수익률·보유기간)를 산출한다
- **FR-13** L2 거울: "'분위기·감'으로 산 최근 N건 평균 −X%" 형식 — 본인 데이터만, 평가어 없이
- **FR-14** 심리매매 지수를 월 단위로 산출·표시한다
- **FR-15** 손실 중 종목 재진입(복수매매 패턴)을 체결 이력에서 식별하고, 해당 인터셉트에 맥락 한 줄을 추가한다
- **FR-16** "실적·분석" 라벨과 실제 성과의 불일치도 판정 없이 기록·표시한다

### FG-3. 생체 신호 (보조)

- **FR-17** Polar H10에서 BLE로 RR 간격을 실시간 수신한다 (`bluetooth-central` 백그라운드)
- **FR-18** HRV(RMSSD)·심박을 개인 시간대별 기준선 대비 편차로 저장한다 (절대 임계치 금지)
- **FR-19** HealthKit에서 수면·안정시 심박을 읽는다 (폴백)
- **FR-20** 라벨·체결·생체를 시각으로 정렬해 H3 분석 데이터셋을 만든다
- **FR-21** 활동(운동)·수면 구간은 각성 판정에서 제외한다

### FG-4. 회고·자가예측

- **FR-22** 아침 1탭 자가예측("오늘 심리 매매 위험이 높을 것 같다 / 아니다")을 수집한다 (H4)
- **FR-23** 주간 회고는 근거 라벨 분포·심리매매 지수 추이·근거별 성과를 보여준다 (시장 데이터는 회고에서만 허용)
- **FR-24** 수집 누락·미응답 구간을 기록하고 분석에서 제외한다

## 5. 비기능 요구사항

- **NFR-1** 인터셉트 화면은 3초 안에 읽히고 탭 1번으로 통과 가능해야 한다 (지하철·한 손 맥락)
- **NFR-2** H10 미착용 시에도 전 기능이 동작한다 (생체는 보조)
- **NFR-3** 사용자 대면 문구는 질문형과 1인칭 사실(L1·L2)만. 권고·명령·판정형 금지 — "지금은 사지 마세요"(시기 판단=자문업 리스크), "심리 매매입니다"(판정) 금지
- **NFR-4** 시장 데이터는 실시간 화면·트리거에 쓰지 않는다 (사후 회고·내부 분석만)
- **NFR-5** 질환명·스크리닝·진단 표방 금지 (웰니스 지위 유지)
- **NFR-6** 생체 데이터 별도 동의, 원시 생체 데이터 서버 미전송(온디바이스)
- **NFR-7** 게이미피케이션 금지 목록 유지: 스트릭·배지·랭킹·달성률·평가어·재진입 유도 푸시. 심리매매 지수는 월 단위·평가어 없이만
- **NFR-8** 배포: 개인 개발자 계정 사이드로드(n=1), 스토어 심사 무관

`[NOTE FOR PM]` 규제 상세(자본시장법·의료기기·개인정보)는 v2 분석 유지 — research-landscape.md. 런칭 전 유권해석+변호사 검토 필요.
