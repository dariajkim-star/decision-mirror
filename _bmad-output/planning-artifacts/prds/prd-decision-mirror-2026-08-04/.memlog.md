- (event) 리서치 digest 저장 완료

- (event) 방법론적 발견: 반복확인 행동 언급글 16건뿐, 감정어 없는 글은 3건. '자기 상태를 인식 못하는 사람은 그것에 대해 글도 쓰지 않는다' → 텍스트로는 상태맹시 순간을 원리적으로 관측 불가. 생체신호 필요성의 데이터 근거가 됨. PRD에 한계로 명시
- (change) PRD 초안 작성 완료(prd.md). 구조: 문제정의/근거데이터/원형/UJ 2개/솔루션/KPI/가설/FR 26개/NFR 12개/금지사항/오픈이슈 6개. UJ는 실제 원문 DM-ID로 추적 가능하게 작성, 추론부는 [ASSUMPTION] 태깅
- (decision) MVP 타겟을 원형A(고빈도 모니터)로 제안 — 행동데이터 밀도 최고, Glance 도달률 최고. [ASSUMPTION] daria 본인 매매습관 확인 후 확정 필요(OI-5)
- (event) Phase-blocker 2건 식별: OI-1 Glance 도달률(제품이 잡으려는 순간=시계 볼 여유 없는 순간, Widget 방식의 구조적 한계), OI-2 Phase A 리텐션(10거래일 무피드백)
- (decision) OI-1(Glance 도달률) 해결: '그 순간에 잡는다'는 전제를 버리고 H4(자기인식 보정)를 주가설로 승격, H2(즉시개입)를 보조로 강등. 거울의 효용은 그날 보는 것이 아니라 매일 봐서 자기 베이스라인을 체득하는 것. 대가: 검증기간 2~3개월로 연장. 문서에는 '해결'이 아니라 '제품정의 변경으로 회피, 대가는 기간 연장'으로 기재(Mary 요구)
- (decision) OI-2(Phase A 리텐션) 해결: 가민 커넥트 과거 데이터(수개월치 심박·수면·스트레스) + 과거 체결통보 이메일 소급 파싱으로 생리 베이스라인을 첫날 확보. Phase A에 남는 것은 행동 베이스라인뿐. 온보딩에서 과거 요약 1회 노출 → 후킹 포인트. 과거는 확정된 데이터라 관측자효과 무관, 단 온보딩 시점을 기록해 이후를 '노출 후'로 분리. T-90~T0가 순수 자연상태 통제기간이 되어 실험설계상 이득
- (decision) H2 오염 대응: Glance 열람 로그를 남겨 ITT(배정기준) 주분석 + 처치받은자(실제열람) 보조분석 병기. 가민 과거데이터 취득은 MVP에서 Connect 웹 수동 내보내기로 충분(Health API 승인 불필요)
